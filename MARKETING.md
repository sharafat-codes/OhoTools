## Reddit (⚠️ read this before posting)

Reddit *hates* obvious self-promotion — a "check out my tool" post gets removed and
downvoted, and blasting the same link across subs fast can get you shadowbanned. Rules:

1. **Read each subreddit's rules first.** Many restrict or ban self-promo.
2. **Lead with value, link second.** The story/usefulness carries the post; the URL is a footnote.
3. **Space it out.** Different sub, different angle, a few days apart. Don't copy-paste identical text.
4. **Reply to comments** — engagement is what keeps a post alive.
5. Best subs for "I built X": **r/SideProject**, **r/webdev** (Showoff Saturday), **r/InternetIsBeautiful**
   (only if genuinely novel), **r/coolgithubprojects**. Regional: **r/developersIndia** (interview prep is big there — but be genuinely helpful, not promotional).

## Facebook — developer groups

**⚠️ Group etiquette (important):**
- Many dev groups **ban self-promo** or only allow it on a specific day/thread — check each group's rules or the pinned post first.
- **Lead with value / a real story.** "I built this free thing, here's the tech, feedback welcome" lands far better than "check out my site."
- **Don't paste the same link into 5 groups in the same minute** — Facebook's spam filter will flag/limit you. Space them out and tweak the wording per group.
- **Reply to every comment.** Facebook boosts posts with engagement; a few good replies = way more reach.
- Post **with an image** — image posts get several times the reach of plain-link posts (prompts below).

### Image tips (for whatever generator you use)

- **AI image tools are bad at text** — keep words out of the prompt image, then add your headline in **Canva** (free) on top. Or accept a text-free graphic.
- **Sizes:** feed/link image **1200×630**; square feed post **1080×1080**.
- **Keep the brand color consistent** across posts — deep violet/purple (#7C3AED) — so people start recognizing OhoTool.
- Tools that work well for these prompts: Gemini (Nano Banana), ChatGPT/DALL·E, Midjourney, or Ideogram (Ideogram is best if you *do* want text baked in).
